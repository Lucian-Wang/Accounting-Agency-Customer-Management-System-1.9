# 代理记账客户管理系统 · 1.9

本系统专为中小代理记账公司设计，基于 **PHP + MySQL**，帮助企业高效管理客户、合同、服务期、分段、周期性与临时收费，并支持合同电子签署、到期/催收提醒、一键导出等功能。

---

## 主要功能

- **客户管理**：客户信息增删改查、唯一性校验、批量导入。
- **合同管理**：合同台账、模板管理、在线电子签署（含签名图片与自动插入）、合同编号与签署时间管理。
- **服务期与分段管理**：支持客户多服务期及分段，适合价格变更、补差、续费等场景；每个服务期可拆分多个分段，独立设置费用与备注。
- **周期性与临时收费管理**：周期收费与临时收费分开管理，自动统计已收/待收金额，避免超额收款，支持预付款、杂费等录入。
- **到期提醒与催收提醒**：自动筛查未收全款和即将到期客户，便于及时催收与续费。
- **权限与多用户管理**：登录后方可访问，支持多用户协作与权限划分，默认账号 admin/123456。
- **数据导出**：一键导出全部业务数据为 CSV，便于分析与归档。
- **数据安全**：所有数据本地存储于 MySQL，便于备份与扩展。

## 快速部署

1. **环境要求**
   - PHP 7.4+（建议 8.x），需启用 PDO MySQL 扩展
   - MySQL 5.7+/MariaDB
   - 支持 Apache/Nginx/IIS/自带 PHP 内置服务器等

2. **数据库部署与配置**
   - 创建 MySQL 数据库和专用账号。
   - 当前仓库提供 `public/install.php` 安装向导。将 Web 根目录设置为 `public/`，访问 `/install.php`，填写数据库信息。
   - 安装器创建表结构并生成 `public/db.php`、`public/install.lock`；不要按旧说明寻找根目录 `db.sql`。

3. **部署步骤**
   - 上传完整项目，保留目录结构。
   - 允许安装器写入生成配置，按实际上传需求配置目录权限。
   - 安装完成后访问 `/index.php`；Web 根目录已是 `public/`，URL 无需再带 `/public`。

## 合同模板变量说明

合同模板支持变量自动替换，常用变量包括：

| 变量名                | 说明                 |
|-----------------------|----------------------|
| `{client_name}`       | 客户名称             |
| `{contact_person}`    | 客户联系人           |
| `{contact_phone}`     | 客户电话             |
| `{contact_email}`     | 客户邮箱             |
| `{remark}`            | 客户备注             |
| `{service_start}`     | 服务期开始日期       |
| `{service_end}`       | 服务期结束日期       |
| `{month_count}`       | 服务月数             |
| `{package_type}`      | 套餐类型             |
| `{price_per_year}`    | 每年价格/分段价格    |
| `{segment_fee}`       | 分段费用（如使用分段）|
| `{seal}`              | 甲方盖章（签章图片） |
| `{signature}`         | 甲方签名图片         |
| `{sign_date}`         | 合同签署时间         |

> 可在模板管理和后台逻辑中扩展其他变量。

## 数据模型与核心业务逻辑

- **主数据表**
  - `contracts`：客户/合同表
  - `contracts_agreement`：合同协议表（含电子签署、签名图片、签署时间等）
  - `contract_templates`：合同模板
  - `service_periods`：服务期
  - `service_segments`：分段
  - `payments`：收费记录
  - `users`：用户

- **业务逻辑简述**
  - 合同金额 = 所有分段金额之和
  - 周期性收费不得超合同金额
  - 催收提醒：自动筛查未收全款的服务期
  - 到期提醒：只提醒未续期的服务期，支持自定义天数
  - 合同电子签署：生成签署链接，客户在线签名，自动记录签署时间与签名图片

- 客户详情页展示服务期（及分段）、临时收费记录

## 常见问题

- **如何重置/备份数据？**  
  直接备份/还原 MySQL 数据库即可。

- **支持多人协作吗？**  
  MySQL 支持多用户在线访问，适合团队协作和高并发场景。

- **如何添加其它字段或功能？**  
  修改表结构和页面即可，代码结构清晰，便于扩展。

- **如何迁移或分布式部署？**  
  拷贝所有 PHP 文件至服务器，配置好 MySQL 数据库连接即可，无需额外依赖。
